# Werkvormen

Elke pagina heeft dezelfde opbouw: thematische inbedding, artistiek statement, werkvorm, nabespreken en *voor onderzoekers*.

1. [Wiens klok?](01-wiens-klok.md): een klok tikt iemands hart, pas of adem. Van wie?
2. [Gym](02-gym.md): Koekoek (beweging) en Herstelslag (intervaltraining met hartslagcheck).
3. [Zweving](03-zweving.md): ieder hart een toon. Samen één toon, kwartet, koor, afstoten.
4. [Beweging](04-beweging.md): sensor & kalibratie, stil-wedstrijd, ademzwerm, wie leidt?
5. [Hartslaggesprek](05-hartslaggesprek.md): zonder woorden, met elkaars hart in je oor.
6. [Is dit mijn hart?](06-is-dit-mijn-hart.md): tellen, herkennen, raden.
7. [Machine-meditaties](07-machine-meditaties.md): vier 3D-mashups van oude machines en software (opwarmen, opschonen, nadenken, bufferen), in eigen tempo of op jouw hartslag, schermvullend voor de expo, met een experiment.
8. [AI-meditaties](08-ai-meditaties.md): drie vaste meditaties en een live-meditatie die op je lichaam reageert.

Los subproject, buiten het Lummellab:

9. [Andere lichamen](../body-intelligence/andere-lichamen.md) in het [B.I.-lab](../body-intelligence/): doe een dier, een machine of een klap na, bouw samen een model dat raadt wat je doet, en fop het. De hele AI-keten in één werkvorm.

Zie [over TUHTF](../over-tuhtf.md) voor de deelvragen, en de [handleiding](../handleiding-docenten.md) voor het geven van een sessie.
